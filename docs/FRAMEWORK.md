# Framework overview

SGCZoom investigates learned, spatially varying zooming for UAV small-object detection.

At a conceptual level, the framework connects image input, a learned zoom branch, geometry-consistent resampling, an object detector, and prediction mapping back to the original image coordinates. Scale-aware supervision and coordinated training support joint optimization.

This document is an overview only. Core algorithms, implementation details, parameter settings, and executable configurations will be released after paper acceptance.
